# Database Systems (BD)

Repository for the **Database Systems (Base de Dados)** curricular unit materials.

This repository gathers lecture notes, slides, and supporting resources covering the main theoretical and practical topics of relational database systems, from conceptual modeling to SQL programming, optimization, and transaction management.

---

## Contents

### Course Topics Covered

- **Introduction to Databases**
  - Database fundamentals and DBMS overview  
  - Relational database concepts  

- **Conceptual Design**
  - Entity-Relationship modeling  
  - Conceptual schema design  

- **Relational Model**
  - Relations, tuples, attributes  
  - Keys and integrity constraints  

- **SQL**
  - DDL (Data Definition Language)
  - DML (Data Manipulation Language)
  - Views
  - Advanced querying  

- **Relational Algebra**
  - Projection, selection, joins
  - Set operations  

- **Normalization**
  - Functional dependencies
  - 1NF, 2NF, 3NF, BCNF  

- **Indexes and Query Optimization**
  - Index structures
  - Clustered vs non-clustered indexes
  - Query performance tuning  

- **SQL Programming**
  - Stored Procedures
  - Functions
  - Triggers
  - Cursors  

- **Transactions, Concurrency, and Recovery**
  - ACID properties
  - Locking mechanisms
  - Rollback / Commit
  - Failure recovery

## Objectives

By the end of this course, the goal is to be able to:

- Design conceptual and relational database schemas
- Normalize schemas correctly
- Write efficient SQL queries
- Implement advanced SQL programmable objects
- Optimize database performance
- Understand transaction safety and concurrency control
